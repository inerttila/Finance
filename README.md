# Net

A private monthly spending ledger. Track what you spend, what’s left, and how the month is pacing — without sharing your numbers with anyone else.

**What it does**

- Opens each month with your income and carries leftover balance forward
- Logs day-to-day expenses by category, person, and note
- Handles fixed costs (rent, subscriptions) that recur automatically
- Shows remaining budget, pace vs plan, and today’s room to spend
- Searches past spending across months
- Keeps savings goals and category setup in Config
- Signs in with email, Google, or GitHub — each ledger stays private to you
